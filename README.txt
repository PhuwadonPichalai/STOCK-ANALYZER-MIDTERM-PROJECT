=======================================================
Mid-term Project: S&P 500 Stock Analyzer (Merge Sort)
=======================================================

Project Description
-------------------
This project applies Data Structures and Sorting Algorithms concepts to real-world financial data. It extracts the fundamental financial data of over 500 companies in the S&P 500 index, analyzes them, and uses the "Merge Sort" algorithm to rank and find the "Top 5 most investable stocks".

Grading Criteria Alignment
-----------------------------
1. The source code is well over 50 lines and runs flawlessly.
2. Applies the algorithm learned in class (Merge Sort) to sort record-based data (2D List).
3. Reads data from a CSV file (following lecture slide 25 - readRecordToList function).
4. Extends the algorithm (Complexity level for >= 80 points) by not sorting on just a single raw value, but by formulating a "Composite Score" to weight and combine 3 fundamental financial factors.

Project Files
------------
1. download_data.py
   - Script to scrape all S&P 500 tickers from Wikipedia.
   - Uses the yfinance module to fetch real-time financial data (ROA, Profit Margin, Debt/Equity).
   - Calculates the total score and saves all data to a CSV file.

2. sp500_fundamentals.csv
   - The database file generated by download_data.py.
   - Stores data in a Record format for easy processing.

3. main.py (Main Program)
   - The main program that reads data from the CSV file into a List of Lists.
   - Sorts the data using Merge Sort in Descending order by specifying a Column Index.
   - Prints the Top 5 highest-scoring companies to the screen.

Composite Score Formula
--------------------------------------
Score = (ROA * 0.4) + (Profit Margin * 0.4) - (Debt to Equity Ratio * 0.2)
* Note: We use ROA (Return on Assets) instead of ROE (Return on Equity) to prevent data distortion in cases where companies heavily engage in Share Buybacks, which can shrink shareholders' equity to near zero.

How to Run
------------
1. Install the required libraries via Command Prompt/Terminal:
   pip install yfinance pandas requests lxml

2. (Optional) Run the script to fetch new data (if the data in sp500_fundamentals.csv is outdated):
   python download_data.py
   *This step takes about 10 minutes to scrape all 500 companies.*

3. Run the main program to sort and view the results:
   python main.py
   *The program will execute the Merge Sort in milliseconds and immediately display the result table.*

Code Execution Workflow (Step-by-Step)
--------------------------------------
Phase 1: Data Preparation (download_data.py)
1. Web Scraping: Extracts the list of S&P 500 companies from Wikipedia using the Pandas library.
2. API Fetching: Iterates through each ticker symbol and requests fundamental data (ROA, Profit Margin, Debt-to-Equity) via the yfinance API.
3. Scoring & Export: Calculates a Composite Score for each stock based on the predefined formula and writes the data line-by-line into a CSV file (sp500_fundamentals.csv).

Phase 2: Data Loading (main.py)
1. File I/O: Opens the generated CSV file and skips the header row.
2. Type Casting & Structuring: Reads each row, converts numerical string values (Score, ROA, Margin, Debt) into Float data types, and appends them to a main list. The resulting data structure is a 2D Array (List of Lists).

Phase 3: Sorting (main.py)
1. Merge Sort Algorithm: A custom recursive merge sort function is called, passing the 2D array and the target column index (key_column = 1, representing the Score).
2. Divide: The array is recursively halved until each sub-list contains only one element.
3. Conquer & Merge: The sub-lists are merged back together. During the merge, the algorithm compares the Score of the left and right items, arranging them in descending order (highest score first).

Phase 4: Display
1. The sorted 2D array is sliced to retrieve only the top 5 elements.
2. The data is formatted and printed out as a clean, aligned table for final presentation.
